Everything between your script and the wrong hands.

Six layers that work together, so a leaked key, a cloned loader or a replayed request never becomes a leaked script.

Challenge-response authentication

Every login starts with a single-use nonce. Keys are proven with a signature and never travel as a replayable token.

HWID and behavioral anti-sharing

Keys bind to a device fingerprint, and usage patterns flag shared accounts before they spread.

Signed script delivery

Scripts are served through signed URLs that expire after 90 seconds and cannot be reused or shared.

Edge network

Authentication runs close to your players, so protection adds no noticeable delay to script startup.

Auto-ban intelligence

Replay attempts, tampered signatures and key sharing trigger automatic bans you can tune per project.

Session tokens

Short-lived tokens keep running scripts validated with light heartbeats, and can be revoked instantly.

Three requests from loader to protected script.

  1. 1

    Get challenge

    Your loader requests a challenge and receives a single-use nonce that expires in 30 seconds.

  2. 2

    Sign and verify

    The loader signs the nonce, key and HWID with HMAC-SHA256. VELUM checks the signature and the device binding.

  3. 3

    Receive signed script and session

    You get a script URL valid for 90 seconds and a session token for heartbeats. Nothing else is exposed.

VELUM Auth v3 API

Three JSON endpoints over HTTPS. Base URL https://api.velum.dev

Single-use nonce

Each challenge works once and expires in 30 seconds.

HMAC-SHA256

Requests are signed, so tampering is detected immediately.

Challenge-response

The raw key is never sent as a reusable credential.

Short-lived URLs

Signed script links expire after 90 seconds.

POST /v3/challenge

Request a nonce for a script and device. The nonce is bound to the HWID and expires after 30 seconds.

Request

{
  "script_id": "scr_8f2a1c",
  "hwid": "7B1E-44A9-C03D-91F2"
}

Response 200 OK

{
  "challenge_id": "ch_9d41e7",
  "nonce": "b7f3a91c04e2d85f",
  "algorithm": "HMAC-SHA256",
  "expires_in": 30
}
POST /v3/verify

Send the signature of nonce|key|hwid. On success you receive a session token and a signed script URL.

Request

{
  "challenge_id": "ch_9d41e7",
  "key": "VLM-4F2A-91CC-7D30",
  "hwid": "7B1E-44A9-C03D-91F2",
  "signature": "5c0e9b2a71d4f8e3a6b9c1d27e40f5a8"
}

Response 200 OK

{
  "status": "ok",
  "session_token": "vs_4e1d92c7a0b3",
  "script_url": "https://edge.velum.dev/s/scr_8f2a1c?sig=e91f03",
  "url_expires_in": 90
}
POST /v3/session/validate

Call on an interval while the script runs. A revoked or banned session returns valid: false.

Request

{
  "session_token": "vs_4e1d92c7a0b3",
  "hwid": "7B1E-44A9-C03D-91F2"
}

Response 200 OK

{
  "valid": true,
  "expires_in": 3540,
  "next_heartbeat": 60
}
